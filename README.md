# Pediatric Hem/Onc Atlas Study Hub

نسخة مخصصة للدراسة الشخصية لامتحان Pediatric Hematology/Oncology.

## ما الذي تغير؟

- مستكشف صفحات للأطالس مع فهرسة حسب الفصل والمحور.
- عرض الصفحة مع تكبير، ونص مستخرج عند توفره.
- اختبار صورة: وصف مورفولوجي أولاً ثم كشف الصفحة والـ board pearls.
- تأشير الصفحات وقبو أحمر للصور الصعبة.
- خطة دراسة مرتبة حسب أولوية البورد.
- وضع MCQ منفصل، مع عدم احتساب الإجابة غير الصريحة صحيحة.
- تنزيل واسترجاع التقدم بملف JSON/CSV بين الأجهزة.
- لا توجد مفاتيح JSONBin إجبارية ولا أسماء أو رسائل شخصية داخل الكود.

## التشغيل على Streamlit

1. ارفع `app.py` و`requirements.txt` ومجلد `.streamlit` إلى مستودع GitHub **Private**.
2. في Streamlit Community Cloud اختَر المستودع، الفرع `main`، وMain file path = `app.py`.
3. Deploy.
4. من داخل التطبيق ارفع ملفات الأطلس من زر رفع الملفات. لا تضع ملفات PDF داخل GitHub.
5. إذا أردت النقل بين الهاتف واللابتوب: من تبويب `📈 تقدمي` نزّل JSON، ثم ارفعه في الجهاز الثاني.

## الملفات الموصى بها

- Rodak Clinical Hematology Atlas — Fifth Edition: المصدر الأساسي للمورفولوجي.
- Hoffbrand Color Atlas — Fourth Edition: مصدر مساعد للصور والسياق.
- Rodak Fourth Edition: نسخة أقدم/مكررة، لا ترفعها إلا إذا احتجت مقارنة صفحة محددة.

## الخصوصية

أبقِ GitHub repository والتطبيق Private. التطبيق يعالج الملفات المرفوعة أثناء جلسة الدراسة ولا يكتبها داخل المستودع. لا تنشر التطبيق Public لأن الكتب والمواد قد تكون محمية بحقوق نشر.

## ملاحظة علمية

الأطلس ممتاز لتثبيت المورفولوجي، لكنه لا يكفي وحده للتصنيف الحديث أو العلاج. عند أسئلة اللوكيميا والتصنيف، قارن مع WHO Classification of Tumours Online وWHO 5th/ICC ومع منهجك الرسمي.
