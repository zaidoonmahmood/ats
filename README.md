# Pediatric Hem/Onc Atlas Exam Hub

نسخة Atlas-only للدراسة الشخصية لامتحان Pediatric Hematology/Oncology.

## الأطالس المدعومة

- Rodak Clinical Hematology Atlas 6th Edition — الملف الذي ظهر باسم `3.pdf`.
- Rodak Clinical Hematology Atlas 5th Edition — `book Dr Maha(1).pdf`.
- Wintrobe's Atlas of Clinical Hematology 2nd Edition — `2.pdf`.
- Anderson's Atlas of Hematology 2nd Edition — `4.pdf`.
- Color Atlas of Clinical Hematology 4th Edition — ملف Hoffbrand.
- Rodak 4th Edition — `6.pdf` أو النسخة العربية المكررة، ويُترك اختيارياً.

`1.pdf` هو Wintrobe's Clinical Hematology 14th Edition، كتاب مرجعي ضخم وليس أطلس صور، لذلك لا يدخل وضع امتحان الصور.

## التشغيل

1. ارفع `app.py` و`requirements.txt` إلى جذر مستودع GitHub Private.
2. اترك ملف `.streamlit/config.toml` إن أمكن؛ هو يرفع حد الملف ويضبط الواجهة، لكنه غير أساسي.
3. في Streamlit اختَر الفرع `main` وMain file path = `app.py`.
4. افتح تبويب `📥 تحميل الأطالس` وارفع كل PDF في حقله الصحيح.
5. استعمل `🔬 مستكشف الأطلس` للقراءة والبحث، و`🧠 وضع الامتحان` لاختبار الصورة قبل كشف المصدر والكابشن.

## الخصوصية

لا تضع ملفات الكتب داخل GitHub. التطبيق يعالجها داخل جلسة الدراسة، لذلك قد تحتاج إعادة رفعها بعد إعادة تشغيل التطبيق. احتفظ بالتطبيق والمستودع Private ولا تنشره Public.

## طريقة الدراسة المقترحة

1. Rodak 5th/6th: foundation, RBC morphology, acute leukemia.
2. Wintrobe/Anderson: المقارنة وتثبيت الصور التي تتكرر بالأسئلة.
3. Hoffbrand: السياق المرضي والصور المساعدة.
4. كل صورة صعبة: اختر `ما عرفتها` حتى تدخل القبو الأحمر.
5. قبل تبديل الجهاز: نزّل JSON من تبويب التقدم.

الأطلس للمورفولوجي؛ أما التصنيف الحديث فراجعه من WHO Classification Online وWHO 5th/ICC والمنهج الرسمي للامتحان.
